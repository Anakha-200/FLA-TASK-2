# FLA Assignment 2 – Finite Automata Case Studies

## Course
21CSC301T – Formal Language and Automata

## Description
This repository contains Python implementations of three DFA-based validation applications developed for Assignment 2.

## Programs Included

1. Username Validator
   - Validates usernames using a Deterministic Finite Automaton (DFA).

2. Email Validator
   - Validates email addresses using a DFA.

3. PDF File Name Validator
   - Validates PDF file names ending with the `.pdf` extension using a DFA.
